# Original frog artwork

Four original SVG illustrations, authored for Frogs of the Swarm. The character has round cream eyes, a small curved smile, three lily-shaped forehead freckles, rosy cheeks, and rounded webbed feet. The stages keep these features while changing the tail, limbs and crown. No existing character, brand, photograph or reference artwork was used.

| File | Accepted jobs | Stage |
| --- | --- | --- |
| `tadpole.svg` | 0–99 | Tadpole: tail, no legs |
| `froglet.svg` | 100–999 | Froglet: small legs and a remaining tail |
| `frog.svg` | 1,000–1,999 | Frog: adult with webbed feet |
| `king-frog.svg` | 2,000+ | King Frog: same adult with a small crown |

Each asset has a `320 × 320` viewBox, a transparent background, descriptive SVG title and description, and no scripts, external references, fonts or dependencies. SVG was chosen so the illustration stays sharp at any card size. Apply CSS `filter: hue-rotate(...)` to the image for a deterministic color per agent. The small illustrated crown belongs to the King Frog experience level; a separate page crown denotes the weekly vote winner at any experience level.
